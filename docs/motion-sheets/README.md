# Liikkeiden kuvasarjat (vaihe C)

Tuotettu: `node --experimental-strip-types scripts/render-motion-sheets.ts Pipsa Roni-Monikulma --out docs/motion-sheets --png`
(SVG → PNG paikallisella headless-Chromiumilla). Jokaisessa sarjassa 8 tasavälistä ruutua liikkeen ajalta, ruudun numero ja kuvakulma,
punainen lattiaviiva sekä viimeisessä ruudussa jalkaterien ja ranteen jäljet. Hahmo on keskitetty juuren mukaan, jotta askellus näkyy.

Pipsa = etunäkymän leikkaushahmo (ei profiileja), Roni-Monikulma = kolme kuvakulmaa (kävely kääntää profiiliin ja takaisin eteen).
Kuvat ovat simuloituja renderöintejä kerroskuvista ja animaation muunnoksista, eivät sovelluksen kuvakaappauksia.
